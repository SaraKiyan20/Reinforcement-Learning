# Silver Course — Reinforcement Learning (UCL, David Silver)

My implementations of the algorithms from David Silver's
[Reinforcement Learning course](https://www.davidsilver.uk/teaching/) (UCL), split into two parts:

- [`lectures-1-to-5/`](./lectures-1-to-5) — MDPs, Dynamic Programming, Model-Free Prediction (MC & TD),
  Model-Free Control (SARSA, Q-Learning)
- [`lectures-6-to-10/`](./lectures-6-to-10) — Value Function Approximation, Policy Gradient methods,
  Integrating Learning & Planning (Dyna), Exploration & Exploitation (UCB)

Each subfolder has its own notebook, README, and requirements.txt, and runs independently.
